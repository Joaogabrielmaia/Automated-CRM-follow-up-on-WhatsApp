# Episódio 1 — Discovery

Escolhi o Pulso entre cinco ideias, com matriz de decisão. O cenário é uma empresa fictícia de reformas em que o lead esfria depois do orçamento.

Três registros de discovery (dono, atendente e cliente-tipo) são reuniões simuladas. Os números nas respostas são do cenário, não medições.

O dono pede "tudo automático" e teme a mensagem errada em seu nome. A atendente pede mais controle. A restrição de número dedicado na API oficial levou ao provedor plugável e à ação "criar tarefa".

O episódio fecha com o processo atual e seis problemas priorizados, P1 a P6. O P3, o medo de incomodar o cliente, é condição para resolver os outros.
