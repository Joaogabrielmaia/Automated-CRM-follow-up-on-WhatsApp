# Episódio 2 — Definição

O que o produto faz e o que fica de fora, com tudo numerado para poder ser rastreado até um teste.

Os valores padrão das 19 regras de negócio vêm dos registros do Ep. 1 e são configuráveis. As metas M1 a M6 são hipóteses: nenhuma foi medida.
