# Episódio 4 — Protótipo

Os wireframes das quatro telas centrais passaram por três personas simuladas antes de qualquer código.

Dos 10 pedidos registrados, 5 foram aceitos, 3 adiados e 2 recusados, cada um com o motivo. O chatbot e a mensagem "só desta vez" às 22h foram recusados.

O MVP não cresceu: o que entrou reaproveita o motor (ação "criar tarefa", RN-16).
