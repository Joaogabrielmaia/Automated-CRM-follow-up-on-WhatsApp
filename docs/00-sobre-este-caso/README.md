# Episódio 0 — Sobre este caso

O Pulso é um mini CRM para uma empresa fictícia, a Casa Nova Reformas: 6 pessoas, reformas e manutenção residencial, leads vindos de Instagram, indicação e anúncio. O atendimento é feito pelo WhatsApp pessoal do dono, o orçamento vai em PDF e o controle fica numa planilha.

O problema do cenário é o lead que esfria depois do orçamento: ninguém lembra de voltar a falar com ele na hora certa. O difícil não é automatizar o retorno, é fazer isso sem incomodar o cliente. Daí as quatro garantias do produto: horário comercial, sem duplicar mensagem, parada na resposta e opt-out.

Este episódio só situa o cenário. A série completa está no [guia](../INDEX.md).
